# 🏠 Rede SOHO — Configuração e Teste de Conectividade

## 🎯 Objetivo

Montar e configurar uma rede SOHO (Small Office/Home Office) no
Cisco Packet Tracer, estabelecendo a conexão entre os dispositivos
e verificando a comunicação por meio do comando `ping`.

---

## 📚 Conceito

Uma rede **SOHO (Small Office/Home Office)** é uma infraestrutura
de rede utilizada em pequenos escritórios ou ambientes residenciais.

Nesse tipo de ambiente, diferentes dispositivos podem compartilhar
recursos de rede e acesso à Internet por meio de conexões cabeadas
e sem fio.

---

## 🛠️ Atividade prática

Durante o laboratório, realizei a montagem e configuração de uma
rede SOHO no Cisco Packet Tracer.

As atividades realizadas incluíram:

- Montagem dos dispositivos que compõem a rede.
- Conexão dos equipamentos utilizando os cabos adequados.
- Configuração da rede para utilização de DHCP.
- Conexão dos dispositivos utilizando endereçamento automático.
- Configuração de dispositivos para conexão por Wi-Fi.
- Configuração de senha para acesso à rede sem fio.
- Teste de comunicação entre os dispositivos utilizando `ping`.

---

## 🌐 Conectividade

Após a configuração dos dispositivos, foram realizados testes para
